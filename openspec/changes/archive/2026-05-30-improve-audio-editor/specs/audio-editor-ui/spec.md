## ADDED Requirements

### Requirement: Интерактивный waveform с draggable маркерами
Компонент `WaveformDisplay` SHALL визуализировать форму волны аудиофайла и позволять перетаскивать маркеры начала и конца сегмента мышью.

#### Scenario: Отображение waveform после загрузки файла
- **WHEN** аудиофайл декодирован
- **THEN** отображается визуализация амплитуды в виде баров на всю ширину контейнера

#### Scenario: Выделение активного диапазона
- **WHEN** установлены значения start и end сегмента
- **THEN** бары внутри диапазона окрашены в цвет акцента (teal), вне — в нейтральный

#### Scenario: Перетаскивание маркера начала
- **WHEN** пользователь нажимает и тянет левый маркер вправо/влево
- **THEN** значение start обновляется в реальном времени, маркер следует за курсором в пределах [0, end)

#### Scenario: Перетаскивание маркера конца
- **WHEN** пользователь нажимает и тянет правый маркер
- **THEN** значение end обновляется в реальном времени в пределах (start, duration]

#### Scenario: Отображение fade-огибающей
- **WHEN** включён fade-in или fade-out для сегмента
- **THEN** над waveform отображается полупрозрачная SVG-огибающая, показывающая нарастание/затухание

### Requirement: Ввод времени в формате MM:SS.S
Компонент `TrimControls` SHALL принимать и отображать время в формате `MM:SS.S` с клавиатурной навигацией стрелками.

#### Scenario: Отображение времени
- **WHEN** значение start/end передано в секундах (float)
- **THEN** поле показывает время в формате `0:15.0`

#### Scenario: Изменение времени с клавиатуры
- **WHEN** пользователь нажимает ↑/↓ в поле времени
- **THEN** значение изменяется на 0.1 секунды

#### Scenario: Валидация диапазона
- **WHEN** пользователь вводит значение start ≥ end
- **THEN** поле подсвечивается красным, значение не применяется

---

### Requirement: Компонент Fade In/Out с иконками
`FadeControls` SHALL предоставлять кнопки включения/выключения и выбор длительности fade 1–4 секунды.

#### Scenario: Включение fade-in
- **WHEN** пользователь нажимает кнопку fade-in (SVG-иконка нарастания)
- **THEN** кнопка подсвечивается активным состоянием, появляется выбор длительности

#### Scenario: Выбор длительности fade
- **WHEN** fade активен и пользователь выбирает длительность (1/2/3/4 сек)
- **THEN** значение fadeIn/fadeOut обновляется

#### Scenario: Отключение fade
- **WHEN** пользователь повторно нажимает активную кнопку fade
- **THEN** fade выключается, огибающая на waveform исчезает

### Requirement: Панель нескольких сегментов
`MultiTrimPanel` SHALL отображать список дополнительных сегментов (индекс ≥ 2) с кнопкой удаления каждого.

#### Scenario: Добавление сегмента
- **WHEN** пользователь нажимает «Ещё один фрагмент»
- **THEN** в список добавляется новый сегмент с дефолтными значениями start=0, end=30

#### Scenario: Удаление сегмента
- **WHEN** пользователь нажимает × у сегмента
- **THEN** сегмент удаляется, нумерация остальных пересчитывается

#### Scenario: Минимум один сегмент
- **WHEN** в списке только один сегмент
- **THEN** кнопка удаления не отображается

---

### Requirement: Плеер обработанных файлов
`ProcessedResults` SHALL отображать карточки для каждого обрезанного файла с плеером, seek-баром, регулятором громкости и кнопкой скачивания.

#### Scenario: Воспроизведение фрагмента
- **WHEN** пользователь нажимает Play на карточке
- **THEN** начинается воспроизведение этого фрагмента, остальные останавливаются

#### Scenario: Seek по файлу
- **WHEN** пользователь перетаскивает позицию на прогресс-баре
- **THEN** воспроизведение перематывается на выбранную позицию

#### Scenario: Скачивание одного фрагмента
- **WHEN** пользователь нажимает Download на карточке
- **THEN** браузер скачивает MP3-файл с именем `{trackName}_{start}-{end}.mp3`

#### Scenario: Скачивание всех фрагментов
- **WHEN** пользователь нажимает «Скачать все»
- **THEN** последовательно скачиваются все обработанные MP3-файлы

### Requirement: Блок быстрого поиска обложек
`ImageSearchBlock` SHALL показывать 4 ссылки на поиск обложек в Яндекс/Google/Bing/DDG с кастомными иконками движков.

#### Scenario: Поисковый запрос из ID3
- **WHEN** ID3-теги содержат artist и title
- **THEN** запрос строится как «{artist} {title}» с фильтрами wallpaper/wide

#### Scenario: Поисковый запрос из имени файла
- **WHEN** ID3-теги не содержат artist/title
- **THEN** запрос строится из имени файла без расширения

#### Scenario: Открытие ссылки
- **WHEN** пользователь нажимает на кнопку движка
- **THEN** ссылка открывается в новой вкладке с `noopener noreferrer`
