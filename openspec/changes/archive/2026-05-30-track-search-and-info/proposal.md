## Why

SongInfo-страница сейчас показывает моковые данные. Пользователям нужна реальная информация о треке — метаданные, текст, ссылки — получаемая из нескольких источников по одному запросу.

## What Changes

- Добавляется поиск треков через Spotify API: пользователь вводит название и исполнителя, получает список вариантов
- После выбора трека агрегируются данные из Spotify (метаданные, превью, обложка), Genius (текст, авторы, продюсеры, фиче-артисты, дата выхода, язык, популярность, обложка, ссылки на стриминги, связи трека: сэмплы, каверы, ремиксы, интерполяции), Last.fm (теги/жанры, количество слушателей и прослушиваний, похожие треки), Setlist.fm (количество живых исполнений, первое/последнее исполнение, туры, encore), YouTube (ссылка на клип, количество просмотров, лайков), Яндекс Музыка (ссылка)
- Бэкенд добавляет новые маршруты `/api/tracks/search` и `/api/tracks/:id/info`
- Фронтенд SongInfo-страница заменяет мок на реальные данные с отображением всей агрегированной информации

## Capabilities

### New Capabilities
- `track-search`: Поиск треков по названию/исполнителю через Spotify API с возвратом списка вариантов
- `track-info`: Агрегация полной информации о выбранном треке из Spotify, Genius, Last.fm, Setlist.fm, YouTube и Яндекс Музыки

### Modified Capabilities
- `song-info-page`: Страница SongInfo переключается с моковых данных на реальный API

## Impact

- **Бэкенд**: новые роуты в `server/routes/tracks.ts`, новые переменные окружения (`GENIUS_ACCESS_TOKEN` уже есть, нужны `LASTFM_API_KEY`, `SETLISTFM_API_KEY`, `YOUTUBE_API_KEY` опционально)
- **Фронтенд**: `src/pages/SongInfo.tsx` подключается к `api.ts`, новые типы в `api-types.ts`
- **Внешние API**: Spotify (уже подключён), Genius (уже есть токен), Last.fm (бесплатный ключ), Setlist.fm (бесплатный ключ), YouTube Data API v3 (опционально), Яндекс Музыка (публичный поиск без ключа)
- **OpenAPI spec**: обновляется автоматически через zod-openapi
