## Why

Яндекс Музыка сейчас отдаёт только deeplink на поиск — без конкретного трека и без каких-либо метрик. Apple Music в агрегации отсутствует. Оба источника предоставляют полезные прокси-метрики популярности (лайки, позиция в чарте) через публичные API без ключей.

## What Changes

- Яндекс Музыка расширяется: вместо search_url — конкретный URL трека, `likes_count` и позиция в Яндекс Чарте с движением (↑↓)
- Добавляется новый источник Apple Music: позиция в iTunes Top-100 Russia через публичный RSS Apple
- Чарты кешируются in-memory с TTL 1 час (обновляются раз в день, нет смысла дёргать при каждом запросе)
- Фронтенд SongInfo показывает новые секции с лайками и позициями чартов

## Capabilities

### Modified Capabilities
- `track-info`: Яндекс секция расширяется до `url`, `likes_count`, `chart`. Добавляется секция `apple_music` с `search_url` и `chart`.

## Impact

- **Бэкенд**: `server/routes/tracks.ts` — расширить функцию агрегации Яндекса, добавить функцию Apple Music, добавить in-memory кеш чарта
- **Фронтенд**: `src/pages/SongInfo.tsx` — новые секции Яндекс и Apple Music
- **Типы**: `src/lib/api-types.ts` — расширить `TrackInfoResponse`
- **Внешние API**: Яндекс Music неофициальный API (без ключа), iTunes RSS (официальный, без ключа)
- **Новые env-переменные**: не требуются
