## MODIFIED Requirements

### Requirement: Отображение информации о треке
Страница SongInfo SHALL отображать реальные данные из API вместо моковых.

#### Scenario: Поиск трека
- **WHEN** пользователь вводит название или исполнителя и нажимает поиск
- **THEN** отображается список до 10 вариантов треков с обложкой, названием, исполнителем и длительностью

#### Scenario: Выбор трека из результатов
- **WHEN** пользователь выбирает трек из списка
- **THEN** страница запрашивает `/api/tracks/:id/info` и отображает агрегированную информацию

#### Scenario: Отображение агрегированной информации
- **WHEN** данные получены
- **THEN** страница показывает секции: метаданные (Spotify), текст/авторы (Genius), ссылки на YouTube и Яндекс Музыку

#### Scenario: Состояние загрузки
- **WHEN** идёт запрос к API
- **THEN** отображается индикатор загрузки вместо контента

#### Scenario: Источник недоступен
- **WHEN** один из источников вернул null
- **THEN** соответствующая секция скрывается без ошибки

#### Scenario: Ошибка поиска
- **WHEN** API возвращает ошибку при поиске
- **THEN** отображается сообщение об ошибке, форма поиска остаётся доступной
