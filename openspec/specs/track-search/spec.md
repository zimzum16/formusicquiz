## MODIFIED Requirements

### Requirement: Поиск треков по единому запросу
Система SHALL принимать единый текстовый запрос (название и/или исполнитель в одном поле) и возвращать до 20 результатов из Spotify API с учётом транслитерации и раскладки клавиатуры.

#### Scenario: Успешный поиск
- **WHEN** пользователь отправляет GET `/api/tracks/search?q=запрос`
- **THEN** система возвращает массив до 20 треков с полями: `id`, `title`, `artist`, `album`, `duration_ms`, `preview_url`, `cover_url`, `spotify_url`, `popularity`

#### Scenario: Пустой запрос
- **WHEN** параметр `q` отсутствует или пустой
- **THEN** система возвращает 400

#### Scenario: Нет результатов
- **WHEN** Spotify не находит треков
- **THEN** система возвращает 200 с пустым массивом `[]`

---

### Requirement: Транслитерация и двойной поиск
Система SHALL параллельно выполнять поиск с оригинальным запросом и транслитерированной версией, мержить результаты без дублей.

#### Scenario: Кириллический запрос — фонетическая транслитерация
- **WHEN** запрос содержит кириллические символы, начинающиеся с типичных русских букв
- **THEN** система транслитерирует запрос в латиницу (BGN/PCGN) и выполняет поиск с обеими версиями; результаты транслитерации идут первыми

#### Scenario: Кириллический запрос — детекция неверной раскладки
- **WHEN** запрос содержит кириллицу и одно из слов начинается с `ы`, `ь` или `ъ`
- **THEN** система интерпретирует запрос как набранный в русской раскладке с включённым английским текстом и конвертирует посимвольно по карте ЙЦУКЕН→QWERTY

#### Scenario: Латинский запрос — обратная транслитерация
- **WHEN** запрос содержит только латинские символы
- **THEN** система транслитерирует запрос в кириллицу и выполняет поиск с обеими версиями для покрытия русскоязычных исполнителей

#### Scenario: Мерж результатов
- **WHEN** оба поиска возвращают результаты
- **THEN** система объединяет списки, удаляет дубликаты по `id`, ограничивает до 20 треков

#### Scenario: Дополнительный параметр artist
- **WHEN** передан опциональный параметр `artist`
- **THEN** он используется как уточнение в обоих поисковых запросах
