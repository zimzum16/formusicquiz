## ADDED Requirements

### Requirement: Извлечение ID3v2-тегов из ArrayBuffer
Функция `parseID3Tags(buffer: ArrayBuffer): ID3Tags` SHALL извлекать метаданные из заголовка ID3v2 аудиофайла.

#### Scenario: Корректный ID3v2 заголовок
- **WHEN** ArrayBuffer начинается с сигнатуры `ID3` (байты 0x49 0x44 0x33)
- **THEN** возвращает объект с извлечёнными полями: title, artist, album, year, genre

#### Scenario: Отсутствие ID3 тегов
- **WHEN** ArrayBuffer не содержит ID3v2 заголовок
- **THEN** возвращает пустой объект `{}`

#### Scenario: Поддержка ID3v2.3 и ID3v2.4
- **WHEN** файл содержит ID3 версии 2.3 (фрейм `TIT2`) или 2.4
- **THEN** корректно извлекаются текстовые фреймы

---

### Requirement: Починка кириллицы CP1251
Парсер SHALL обнаруживать и исправлять мусорные байты в тегах, закодированных в Windows-1251 (CP1251), которые были ошибочно прочитаны как Latin-1.

#### Scenario: CP1251 мусор в тексте
- **WHEN** строка тега содержит символы «мусора» (latin-1 интерпретация CP1251, например `ÐœÐ°Ñ€Ñ‚`)
- **THEN** строка перекодируется в корректный UTF-8 кириллический текст

#### Scenario: Корректный UTF-8 текст
- **WHEN** строка тега уже корректно закодирована в UTF-8
- **THEN** текст возвращается без изменений

---

### Requirement: Извлечение обложки альбома
Парсер SHALL извлекать обложку из ID3v2 фрейма `APIC` и возвращать её как Blob URL.

#### Scenario: Обложка присутствует
- **WHEN** файл содержит фрейм APIC с JPEG или PNG данными
- **THEN** возвращается поле `coverArtUrl` — строка вида `blob:...`

#### Scenario: Обложка отсутствует
- **WHEN** файл не содержит фрейм APIC
- **THEN** поле `coverArtUrl` не присутствует в результате (или `undefined`)

#### Scenario: Освобождение blob URL
- **WHEN** компонент, использующий coverArtUrl, размонтируется
- **THEN** blob URL должен быть освобождён через `URL.revokeObjectURL()`

---

### Requirement: Fallback на имя файла
Если ID3 title отсутствует, SHALL использовать имя файла без расширения как title.

#### Scenario: Нет тега title, есть имя файла
- **WHEN** ID3 не содержит фрейм TIT2, но файл называется `Кино - Группа крови.mp3`
- **THEN** возвращается `{ title: 'Кино - Группа крови' }`

#### Scenario: Формат «Исполнитель - Название»
- **WHEN** имя файла содержит ` - ` как разделитель
- **THEN** часть до ` - ` используется как artist, часть после — как title

---

### Requirement: Чтение только области тега
`extractID3Tags(file)` SHALL читать из файла только 10-байтный заголовок и сам тег (`file.slice`), а не весь MP3.

#### Scenario: Большой файл
- **WHEN** загружен MP3 на 50 МБ с тегом на 200 КБ
- **THEN** в память читается ~200 КБ, а не весь файл

---

### Requirement: Запись ID3 в нарезанные фрагменты
Каждый экспортированный фрагмент SHALL начинаться с ID3v2.3-тега (`buildID3v2` в `id3Writer.ts`) с полями TIT2, TPE1, TALB, TYER, TCON и APIC из текущего `audioFile`. Текст пишется в UTF-16 с BOM.

#### Scenario: Подтверждённые метаданные
- **WHEN** title/artist/обложка уточнены через Spotify/iTunes
- **THEN** в тег фрагмента попадают уточнённые значения, а не исходные (с водяными знаками сайтов)

#### Scenario: Неизвестный исполнитель
- **WHEN** `audioFile.artist === 'Неизвестный исполнитель'`
- **THEN** фрейм TPE1 не пишется

#### Scenario: Обложка недоступна
- **WHEN** загрузка обложки по URL падает (сеть, CORS)
- **THEN** фрагмент сохраняется без APIC, экспорт не прерывается
